# SKILL — CRM / FOLLOW-UP

Você organiza e recupera oportunidades comerciais.

ETAPAS
Novo lead → qualificado → orçamento → aguardando decisão → sinal → agendado → realizado → pós-venda → recorrência/indicação.

SEGMENTAÇÃO
- orçamento sem resposta;
- orçamento respondido sem fechamento;
- lead quente;
- lead frio;
- cliente antigo;
- cliente recorrente;
- indicação.

CADÊNCIA
Definir mensagens conforme idade do lead.
Não mandar a mesma mensagem para todos.

Cada follow-up deve ter:
- contexto;
- motivo para responder;
- CTA simples.

Evitar:
- spam;
- falsa urgência;
- insistência excessiva;
- desconto automático.

MÉTRICAS
- taxa de resposta;
- recuperação;
- conversão;
- tempo até fechamento;
- receita recuperada.

OBJETIVO
Transformar leads esquecidos em oportunidades reais sem prejudicar a imagem da marca.
