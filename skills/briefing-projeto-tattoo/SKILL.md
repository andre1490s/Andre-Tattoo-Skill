# Briefing do projeto de tattoo

Transforma conversas soltas com o cliente em uma ficha de uma página que o Andre abre na hora de desenhar e no dia da sessão.

## Passos
1. Ler a conversa inteira antes de escrever. Se tiver mais de uma conversa do mesmo cliente, juntar tudo.
2. Separar o que o cliente **decidiu**, o que ele **quer mas está em dúvida** e o que **não quer** (tudo que ele rejeitou é tão importante quanto o que pediu).
3. Pegar os dados técnicos: local do corpo, tamanho, estilo, cores, referências.
4. Pegar os dados comerciais: valor passado, número de sessões, sinal, datas.
5. Montar a ficha no formato abaixo.
6. Terminar com as perguntas que ainda faltam, já escritas como mensagem pronta para enviar ao cliente.
7. Conferir: todo pedido, medo ou restrição que o cliente citou está na ficha?

## Formato (sempre este, nesta ordem)

**Projeto: [nome do cliente] — [tema em poucas palavras]**
**Data da ficha:** [hoje]

**A ideia em uma frase:** ...

**Técnico**
- Local: ...
- Tamanho: ... (cm, se o cliente disse)
- Estilo: ...
- Cores: ...
- Referências: [links/fotos citados]

**O cliente quer**
- ...

**O cliente NÃO quer**
- ...

**Pontos de atenção** (medos, pele, cicatriz, tattoo antiga para cobrir, prazo apertado)
- ...

**Comercial**
- Valor: ... | Sessões: ... | Sinal: ... (pago / pendente)
- Data prevista: ...

**Falta saber** + mensagem pronta:
> [mensagem curta, tom do Andre, para enviar ao cliente pedindo o que falta]

## Regras
- Não inventar nada: se o cliente não disse o tamanho, escrever "não definido" em vez de chutar.
- Valores, datas e medidas copiados exatamente como estão na conversa.
- Pedidos firmes do cliente ("ela insistiu", "faço questão") vão em **negrito**.
- Seção sem conteúdo é removida, exceto "Falta saber", que sempre aparece.
- Máximo de uma página.
- A mensagem pronta usa tom próximo e direto, sem emojis em excesso, e assina como Andre.
