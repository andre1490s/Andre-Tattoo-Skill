# Saídas dos agentes

O que os agentes entregam em arquivo (roteiro de carrossel, receita de edição, lista de follow-up,
fechamento do mês) fica aqui. **Esta pasta não vai para o GitHub** — é onde pode haver nome de
cliente, mensagem pronta e número por projeto.

O que vai para o repositório é só o resumo sem dado de cliente: `painel/dados/` e o `painel/index.html`.
